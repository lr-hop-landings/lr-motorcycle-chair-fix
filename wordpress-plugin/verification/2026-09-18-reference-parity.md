# Точность переноса главного лендинга — 0.4.0

Дата: 2026-09-18. Источник: `src/pages/index.astro`, сборка `npm run build`.
Назначение: локальный WordPress `http://testing-gutenberg.local/?page_id=11`.
Тема: Twenty Twenty-Five; шаблон: `lenremont-landing`.
Рабочий сайт lenremont.ru не изменялся.

## Что изменено

Предыдущий JSON реконструировал содержимое через типовые секции и потому не мог точно воспроизвести исходные карточки, иллюстрации и интерактивность. Новый экспорт `wordpress-plugin/export-reference.mjs` преобразует собранную главную страницу в профиль JSON v2 `astro-main-v1` и дерево из 468 блоков, 13 секций. Это не монолитный `core/html`.

Перенесены оригинальные цвета, сетки, изображения, SVG, шрифты, карусель, восемь сравнений до/после, квиз, FAQ, окна связи и мобильная панель. Стили ограничены `.lr-reference`, имена шрифтов изолированы от других Manrope на странице. Сохранён вес селекторов Astro после удаления служебных атрибутов. Убраны служебные переносы HTML в нативном RichText; текстовые узлы кнопок не получают лишних обёрток. Для CSS явно указана UTF-8. Правила темы больше не сбивают центрирование диалогов.

Исправлено предупреждение редактора при обращении к индексу 0 списка зарегистрированных шаблонов: список нормализуется только при наличии ключа нашего шаблона. Ядро WordPress и тема не редактировались.

Дополнительно визуально просмотрены мобильный первый экран, карточки техники, секция услуг, портфолио и окно сообщения. ## Проверенные сценарии

- Повторный импорт через реальную боковую панель Gutenberg, подтверждение замены, сохранение страницы, повторное открытие редактора; ошибок валидации блоков нет, Save неактивна после загрузки.
- Карусель: следующий кейс меняет transform и включает предыдущую стрелку.
- До/после: изменение range 52 → 53 обновляет `--compare-position: 53%`.
- Ссылка «Описать мою ситуацию» открывает второй шаг ветки посадки.
- Ветка квиза: жёсткость → мотоцикл → Telegram → соответствующая рекомендация и контактные поля. Номер и другие персональные данные не вводились, заявка не отправлялась.
- FAQ разворачивает ответ; знак минус после исправления кодировки отображается корректно.
- Окно подготовки сообщения учитывает ответы квиза. Escape закрывает окно и возвращает фокус на вызвавшую ссылку.
- Окно обратного звонка открывается; отправка с пустым телефоном недоступна.
- Мобильная панель расположена внизу окна; кнопка подбора переводит к квизу и фокусирует заголовок.
- Ошибок консоли на проверенной странице и в редакторе нет. Загруженных битых изображений внутри лендинга не обнаружено; невидимые карточки используют исходную lazy-загрузку.

## Границы результата

- Обработчик заявок не подключён. Успешная отправка не имитируется; реальные сообщения/звонки не выполнялись.
- Перенесена главная страница. Четыре связанных посадочных страницы ещё требуют отдельного импорта.
- Содержимое SVG, служебных окон и сценарий квиза пока задаются профилем плагина, а не полной панелью настроек Gutenberg. Основной текст, изображения и ссылки редактируются отдельными блоками.
- Профиль точного переноса предназначен для этой сборки; базовый импорт произвольного HTML по-прежнему не переносит произвольный CSS/JavaScript.
- Предыдущая версия страницы сохранена в `testing-gutenberg.wordpress.2026-09-18.000.xml`; старые ZIP-пакеты оставлены.
