# Библиотека блоков 0.9.0 — локальная проверка

Окружение: testing-gutenberg.local, WordPress 7.1.1, Twenty Twenty-Five, PHP Local 8.2.29. Production не изменялся.

## Результат

- Расширен существующий каталог нативных несинхронизированных паттернов до 17: 12 секций, 3 элемента и 2 страницы.
- Добавлена панель «Библиотека Ленремонт» с категориями, поиском, предпросмотром и вставкой.
- Панель создаёт одну корневую группу, вставляет секции после выбранной, элементы в ближайшую группу, не заменяет существующее содержимое и не смешивает библиотеку с reference-лендингами.
- Контролы цвета/отступов применяются к группам-секциям библиотеки; Gutenberg остаётся основным редактором содержимого.
- Сохранён отдельный черновик 38: 12 секций / 145 блоков. Статус draft, шаблон lenremont-landing. Изменены тестовый H1, фотография/alt первого экрана и схема/отступы контактов. Использована уже имеющаяся локальная фотография из плагина; медиа не отправлялись на внешний сайт.
- До установки сделана резервная копия локального плагина: `local-before-0.9.0.zip`. Пять изменявшихся существующих файлов локальной версии предварительно сравнены с архивом 0.8.0: совпадали, пользовательские правки не перезаписаны.

## Проверено в настоящем браузерном Gutenberg

- Все 17 финальных паттернов парсятся без невалидных блоков, включая полный и пустой корневые контейнеры.
- Вставка 12 секций поочерёдно через UI панели. Сохранение штатной кнопкой Save draft и повторное открытие: один корень, 12 секций, невалидных блоков нет.
- Изменение H1 через RichText, вставка локального изображения через Insert from URL, изменение alt и сохранение. Контроль фронтенд-HTML подтвердил новые значения.
- Смена контактов на серую схему и компактные отступы; значения сохранились после перезагрузки.
- Предпросмотр преимуществ визуально проверен: три оформленные карточки.
- Повторные контакты вставились после выбранного Hero с якорем `lr-ai-contact-2`. Отмена вернула исходные 12 секций.
- Попытка вставить полную страницу при существующем контейнере отклонена с понятным сообщением.
- Отдельная карточка вставилась во вложенную группу; отмена проверена.
- Перемещение преимуществ кнопкой Move down меняет порядок секций; отмена восстановила исходный порядок.
- Поиск «галерея» оставляет одну соответствующую заготовку.
- FAQ раскрывается на фронтенде (нативный details).
- Десктоп 1455 px: один корень, нет горизонтального переполнения, двухколоночный Hero, все внутренние ссылки на якоря имеют цели.
- Телефон 390 px: одна колонка (354 px внутри секции), кнопки на всю ширину, нет горизонтального переполнения; выполнена визуальная проверка. Эмуляция после проверки сброшена.
- После проверок нет несохранённых изменений в тестовом редакторе.

## Автоматические проверки

- `tests/library.test.cjs`: уникализация якорей, переназначение внутренних ссылок, сохранение внешних ссылок и исходных блоков, переключение классов без потери посторонних классов.
- `tests/editor-layout.test.cjs`: современный layout для reference/library; восстановление настройки после удаления корня.
- `tests/verify-library.php`: 17 зарегистрированных паттернов, draft 38, 12 секций, изменённый заголовок, сохранённые настройки секции, один корневой ID.
- `tests/classic-compat.php`: runtime-симуляция классической темы без переключения активной темы. У library и пяти старых reference-страниц нет лишних внутренних wrapper; обычные группы неизменны. Структура всех Swiper-слайдов сохранена.
- Регрессии SEO, converter, пяти JSON и квиз-переходов проходят.
- PHP lint и JS syntax check проходят.

## Границы проверки

- Это локальный выпуск, не доказательство визуальной совместимости с production-темой X. Проверка классической темы здесь серверная, без смены темы и отдельного визуального прогона X.
- Нативная ручная вставка паттернов через «+» не пользуется защитами панели: размещение внутри корня и уникальность якорей контролирует автор. Это указано в инструкции.
- Новые формы отправки, слайдер галереи, REST API и MCP в эту доработку не входят. FAQ не требует JS, галерея использует CSS-сетку.
- На Local при CLI-запуске остаётся прежнее предупреждение отсутствующей php_imagick.dll; к библиотеке не относится.
