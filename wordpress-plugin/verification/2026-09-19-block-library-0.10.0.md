# Библиотека 0.10.0 — локальная проверка

Среда: testing-gutenberg.local, WordPress 7.1.1, PHP 8.2.29, Twenty Twenty-Five. Основной сайт не открывался для изменения и не обновлялся.

## Изменения

- 17 → 37 несинхронизированных заготовок (31 секция, 3 элемента, 3 страницы).
- Новый `lenremont/service-quiz` зарегистрирован через block.json; PHP-рендер, отдельный editorScript и viewScript. Справочник: [WordPress block metadata](https://developer.wordpress.org/block-editor/reference-guides/block-api/block-metadata/).
- CSS только в существующей области `.lr-ai-page` / `#hop-gutenberg.lr-ai-page`; исходные reference-стили и старые интерактивные блоки не изменялись.
- Вопросы настраиваются без JSON. Поддерживаются 1–8 вопросов, 2–12 ответов, два вида ответов, возврат, сброс, короткие плавные переходы, reduced motion.
- Доставка формы остаётся ответственностью HOP. Локальный код валидирует и нормализует телефон, передаёт контекст; без обработчика показывает резервный способ связи.

## Данные и безопасность

- Резервная копия плагина до обновления: `local-before-0.10.0.zip` в этой папке.
- Новый черновик ID 44, slug `lr-library-quiz-demo`, маркер `_lr_block_library_demo=0.10.0`. Не опубликован.
- Создан из паттерна страницы с квизом. Через настоящий UI изменён первый вопрос на «Какая помощь вам нужна?», выбран вариант «Две колонки», сохранён и открыт заново.
- Через библиотеку добавлен второй квиз строками для демонстрации и теста независимости. Итого восемь секций. Страница 38 и пять исходных лендингов не перезаписывались.
- Никаких заявок не отправлено: проверка submit выполнена только локально с синтетическим номером и обработчиком-заглушкой, предотвращающим отправку. Тестовые значения очищены перезагрузкой.

## Ограничения

- Квиз последовательный, не ветвящийся, не калькулятор. Примерные тексты, фото-заготовки и цены требуют заполнения.
- Доставка через настоящий HOP на lenremont.ru не тестировалась. Совместимость проверена по контракту и локальному stub, не по исходникам внешнего плагина.
- Ручная вставка custom quiz вне корневой группы не поддерживается; используйте секции библиотеки.
- Общий CSS меняет внешний вид страниц библиотеки, но не их содержание и не исходные reference-лендинги.
- Предупреждение Local CLI о недостающем php_imagick.dll существовало до работы и не относится к плагину.
