# SEO import 0.8.0

## Scope

Inspected production editor post 350101 without editing fields or saving. Yoast 28.2 assets are present, but the visible SEO controls are custom legacy fields in `on_page`, not the standard Yoast editor store. Their exact IDs are `on_yoast_wpseo_title`, `metadesc`, `bctitle`, `bctitle_url`, `canonical`, `opengraph-title`, `opengraph-description`, `opengraph-image-id` (each with the same prefix).

The integration fills these existing form controls and emits input/change events. WordPress submits the metabox using its normal save flow; the site's existing PHP handler remains responsible for persistence and Yoast output. No new endpoint, direct database write, competing meta tags, or production plugin installation was added. Standard Yoast sidebar on other sites is explicitly not claimed as supported.

## Behavior

- Automatic SEO filling when importing a manifest, enabled by default.
- SEO-only button for already imported pages without replacing blocks, title, slug or template.
- Existing nonempty values preserved unless overwrite explicitly enabled.
- Missing/empty keys never clear existing fields. Missing controls reported, not silently treated as success.
- Undo restores only fields not changed manually since application.
- Five updated JSON examples have individual SEO title, description, breadcrumb title and OG title/description.
- Canonical, breadcrumb URL and OG media-library image ID are opt-in. Robots/indexing and redirects untouched.

## Tests

- Unit tests: exact field mapping, missing fields, empty values, unsafe URLs/types, preserve/overwrite, native events, undo, stale plan detection and all five example schemas.
- Real local Gutenberg on a single temporary draft, with a local-only legacy metabox fixture reproducing the inspected field names and native WordPress metabox save. This is not a copy of the production custom PHP handler.
- SEO-only: four fields filled, existing manual title preserved; save persisted values. Original paragraph was unchanged.
- Explicit overwrite: title replaced. Undo returned the manual title.
- Full import: 418 valid blocks, SEO updated automatically; draft saved. PHP assertions verified all five persisted values and draft status.
- Converter/manifest/editor-layout/quiz regression tests and PHP syntax checks passed.

Production end-to-end save/output still requires installing 0.8.0 and saving an intended page through its existing handler. Production was inspected only; no content or field values changed there.
