# 0.12.0 — самостоятельные секции, 2026-09-19

Изменён только testing-gutenberg. Резервная копия плагина: local-before-0.12.0.zip. Существующие страницы не переписывались.

- 17 зарегистрированных блоков `lenremont/section-*` в штатном inserter, готовые InnerBlocks-шаблоны, настоящие визуальные примеры. Секция сохраняется одним именованным блоком с редактируемыми дочерними блоками; дополнительная HTML-обёртка на фронтенде не создаётся.
- Девять служебных/устаревших блоков скрыты из inserter; ранние паттерны доступны из дополнительной коллекции панели, но не смешиваются с новыми блоками в «+».
- Создан черновик 54. Через стандартный «+» добавлены Hero, цены, FAQ, контакты. Проверены автоматический единичный контейнер, последовательная вставка, сохранение, повторное открытие, перемещение контактов вверх и обратно.
- Альтернативный Hero через «+» отклонён с уведомлением; ранее сохранённые секции остались на месте. Сохранённые конфликтующие блоки автоматически не удаляются, выдаётся предупреждение.
- Все 19 заготовок панели после оборачивания в новые блоки проходят настоящий Gutenberg parse/serialize без invalid blocks. Старый контент 50/51 валиден и не мигрирует автоматически.
- В предпросмотре 54: 4 секции, один hop-gutenberg, уникальные ID, рабочая инициализация квиза, нет editor-only обёрток. На 390×844 ширина документа 390, битых загруженных изображений и ошибок консоли нет.
- Пройдены Node: section-blocks, reference-library, library, editor-layout, SEO, quiz-transition, converter, все пять manifests. PHP: lint, verify-section-blocks, verify-reference-library, classic-compat.
- Реальная доставка заявок и production в этой задаче не тестировались. Существующее предупреждение Local о php_imagick.dll не связано с плагином.

Новые секции предназначены для отдельной страницы с исходным контейнером. Квиз сохраняет исходный сценарий мотосидений. Ручное изменение ID и структуры дочерних блоков может нарушить взаимодействия; текущие ограничения описаны в BLOCK-LIBRARY.md.
