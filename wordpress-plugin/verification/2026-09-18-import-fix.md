# Проверка главного лендинга — 18 сентября 2026

Среда: Local WordPress `testing-gutenberg.local`, страница ID 11, тема Twenty Twenty-Five, Lenremont Page Importer 0.3.0.

## Причина потери контента

При очистке inline-разметки конвертер обходил и заменял служебные узлы `html`/`body`, созданные `DOMParser`. В результате возвращалась пустая строка и в `post_content` сохранялись пустые заголовки, абзацы и кнопки. Старый Node-тест запускал другой путь без `DOMParser`, поэтому не обнаруживал ошибку.

Теперь содержимое `body` копируется рекурсивно: текст и разрешённое форматирование сохраняются, опасные элементы и URL удаляются. Добавлен браузерный регрессионный тест.

## Проверено

- Node-тесты конвертера и проверка JSON: 13 секций, 300 блоков, без предупреждений.
- Нативный браузерный тест: 11 проверок прошли, все 179 текстовых блоков непустые.
- PHP lint всех PHP-файлов плагина; WP smoke test регистрации и рендеринга блоков.
- Повторный импорт через интерфейс Gutenberg, подтверждение замены, сохранение, перезагрузка: тексты сохранены, сообщений о невалидных блоках и ошибок консоли нет.
- На публичной локальной странице один H1, нет неработающих изображений.
- На настольном и мобильном экранах нет горизонтального переполнения; мобильная проверка при viewport 390×844 (ширина содержимого 375 с учётом полосы прокрутки).
- Квиз: задача → уточнение → техника → способ связи → исходная рекомендация. Фактически пройдена ветка «Восстановить обивку / Разрыв или трещины / Мотоцикл / Telegram».
- FAQ раскрывает текст ответа. Ползунок «до/после» изменяет значение и CSS-положение разделителя (50 → 51%).

До замены страницы сохранён WXR-экспорт: `testing-gutenberg.wordpress.2026-09-18.000.xml`. Рабочий сайт lenremont.ru не менялся.
