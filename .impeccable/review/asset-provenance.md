# Проверка provenance растров

Дата: 2026-09-16. Область: `src/data/cases.ts`, `src/data/vehicles.ts`, общие секции и компоненты, а также ссылки `<img>` в текущем `dist` пяти страниц.

Найдено 22 фактически используемых растра. Для 21 существующего файла добавлены совместимые с `embed-prompt` sidecar-файлы `<image>.json`: 16 изображений из `cases.ts`, 2 изображения `reference` и 3 графических QR-кода. Записи прямо обозначены как **origin record, not a generation prompt**: `pre-existing repository asset`, относительный путь, исходное происхождение и промпт неизвестны. Для предметных изображений указано использование как иллюстрации, без подтверждения реального заказа. QR-коды отмечены как существующая контактная графика.

Известный точный промпт нового кресла сохранён без изменений в `src/assets/vehicles/buggy-seat.webp.json`. Новые промпты не придумывались. Бинарные файлы не менялись: SHA-256 всех 21 переиспользованного файла совпадает с хешем, снятым перед записью sidecar. В пяти публичных sidecar нет абсолютных путей, пользовательских каталогов или внутренних данных генерации.

## Итог сканирования

`embed-prompt --scan` выполнен только для четырёх затронутых каталогов ассетов:

| Каталог | Всего растров | Используется страницами | Без provenance после проверки |
| --- | ---: | ---: | ---: |
| `src/assets/motoSeat` | 30 | 16 | 14, все неиспользуемые |
| `src/assets/vehicles` | 1 | 1 | 0 |
| `public/assets/reference` | 2 | 2 | 0 |
| `public/assets/social` | 3 | 3 | 0 |

Итого: у всех 22 используемых растров есть запись provenance. Сканирование `motoSeat` возвращает код 1 из-за перечисленных ниже неиспользуемых файлов; остальные три сканирования возвращают код 0.

Неиспользуемые файлы в `src/assets/motoSeat`, оставленные без изменений и без новых записей:

- `case02-sport-before.webp`, `case03-cafe-before.webp`, `case04-cruiser-before.webp`;
- `case05-scooter-before.webp`, `case06-enduro-before.webp`, `case07-atv-before.webp`, `case08-touring-before.webp`;
- `materialsStaging.webp`, `workshopStaging.webp`, `wornSeatBefore.png`, `wornSeatBefore.webp`;
- `source/finished-seat-staging.png`, `source/materials-staging.png`, `source/workshop-staging.png`.

## Ограничения

- Локальная запись фиксирует наличие старого ассета в репозитории. Она не восстанавливает автора, источник или промпт и не подтверждает реальную выполненную работу.
- Главная страница по-прежнему отображает восемь пар «до/после» и тексты с описанием выполненных работ. Новые sidecar не подтверждают эти утверждения. На страницах типов техники используются подписи иллюстраций. Страницы в этом этапе не редактировались.
- Sidecar в `src/assets` остаются частью репозитория; в проверенном `dist` они не сопутствуют файлам с хешированными именами в `_astro`. Sidecar в `public/assets` попадут в публикацию при следующей сборке и содержат только допустимые публичные записи происхождения.
- Неиспользуемые исходники, макеты и скриншоты проверки не входят в этот аудит. Содержимое QR-кодов в этом этапе не декодировалось и не изменялось.
