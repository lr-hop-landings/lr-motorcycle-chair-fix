# Конкурентный обзор: перетяжка мотосидений в Санкт-Петербурге

**Дата:** 2026-07-21

## Ландшафт

Конкуренты расходятся по сильным сторонам: «Альф» лучше упаковывает специализацию и эстетику, Carinterier глубже раскрывает семантику и публикует цены, мебельная мастерская лучше всех организует расчет по фото, Ivan Custom Garage показывает самый убедительный объем реальных работ. Свободна комбинация этих преимуществ с надежным корпоративным процессом.

## Позиционирование

Условная карта: от «частное ремесло» к «корпоративному сервису» Ivan → «Альф» → Carinterier → мебельная мастерская/Lenremont. По оси «цена/утилитарность → кастом/премиум» мебельная мастерская находится слева, Carinterier и «Альф» — справа. Lenremont выгоднее занять центр: понятная практичная перетяжка плюс кастомные опции по запросу.

## Возможности

1. Сделать расчет по фото главным действием, но честно назвать его предварительным.
2. Показать профильную цену вместо общего прайса ремонта мототехники.
3. Поднять реальные пары до/после сразу под hero.
4. Объяснить материалы через условия эксплуатации и технические карты.
5. Использовать сильные стороны Lenremont — прием, документы, логистика и гарантийный канал — только после подтверждения их применимости к услуге.
