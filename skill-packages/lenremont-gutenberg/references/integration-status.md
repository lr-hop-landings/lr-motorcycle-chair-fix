# Состояние IDE / CLI / REST / MCP

**Реализовано:** offline CLI с информацией о комплекте, созданием рабочей копии и v1 JSON, структурной проверкой JSON, запуском Node-тестов, сборкой editor CSS и ZIP. Ручной импорт в открытом Gutenberg через плагин. Все операции CLI локальны, не подключаются к WP.

**Не реализовано:** общий production-grade headless Gutenberg compiler, REST API импорта, MCP-сервер, ключи Application Password, план/применение импорта, серверный SEO-адаптер и upload медиа.

Для продолжения интеграции прочитайте [ide-import-spec.md](ide-import-spec.md). Это сохранённая спекa от 2026-09-19 с базой 0.8.0: перед реализацией актуализировать по 0.13.0 и нужному сайту. Сначала общий компилятор с тестом эквивалентности и серверный сервис/REST; MCP — тонкий клиент того же контракта. Установка скилла не является установкой такого API.

Не зарегистрировать вымышленные endpoint/tool names в IDE, не менять её MCP-конфиг и не создавать постоянные доступы в рамках обычной сборки JSON. Для агентных IDE без поддержки Codex skills можно явно прочитать SKILL.md и вызывать Node CLI по абсолютному пути. Автообнаружение в произвольной другой IDE не гарантируется.
